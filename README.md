# Discord2

### [PT-BR]

Projeto inspirado na interface do Discord desenvolvido com foco em estudo de interfaces modernas, responsividade e experiência do usuário.

Além da recriação visual, o projeto foi pensado como parte de uma visão maior: integrar futuramente funcionalidades sociais e colaborativas dentro de plataformas de estudo e aprendizado digital.

A proposta era utilizar a estrutura de comunicação inspirada no Discord para criar ambientes mais interativos entre estudantes, permitindo troca de conhecimento, organização de grupos e experiências de aprendizado mais dinâmicas.

O projeto também serviu como prática de:
- estruturação frontend,
- componentização visual,
- responsividade,
- organização de layouts,
- experiência do usuário,
- e construção de interfaces modernas.

### Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

### Objetivo
Explorar conceitos de interface social aplicada à educação digital, utilizando desenvolvimento web como base para futuras integrações em plataformas de ensino.

### [ENG]

Project inspired by Discord's interface, developed to study modern UI design, responsiveness, and user experience.

Beyond the visual recreation, the project was designed as part of a broader vision: integrating collaborative and social features into digital learning platforms in the future.

The idea was to use a Discord-inspired communication structure to create more interactive study environments, enabling knowledge sharing, group organization, and dynamic learning experiences.

This project also served as practice for:
- frontend structure,
- visual component organization,
- responsive layouts,
- user experience,
- and modern interface development.

### Technologies
- HTML5
- CSS3
- JavaScript

### Goal
Explore concepts of social interfaces applied to digital education using web development as the foundation for future learning platform integrations.
